<h3>Prerequisites</h3> <ul> <li><a href="https://nodejs.org/">Node.js</a> (v18 or later recommended)</li> <li><a href="https://www.mysql.com/">MySQL</a> (v8+)</li> <li>A <a href="https://razorpay.com/">Razorpay</a> account (test keys are fine) for payments</li> <li>An email account / app password for stock alert emails</li> </ul> <h3>1. Clone the repository</h3> <pre>git clone https://github.com/&lt;your-username&gt;/&lt;your-repo-name&gt;.git cd &lt;your-repo-name&gt;</pre> <h3>2. Set up the database</h3> <pre>CREATE DATABASE billing_db;</pre> <blockquote>Tables are created from the Sequelize models / backend setup. Update the database name to match your <code>config/db.js</code>.</blockquote> <h3>3. Configure environment variables</h3> <p>Create a <code>.env</code> file inside <code>backend/</code> (adjust names to match your code):</p> <pre>PORT=5000 DB_HOST=localhost DB_USER=your_mysql_user DB_PASSWORD=your_mysql_password DB_NAME=billing_db JWT_SECRET=your_secret_key RAZORPAY_KEY_ID=your_razorpay_key_id RAZORPAY_KEY_SECRET=your_razorpay_key_secret EMAIL_USER=your_email@gmail.com EMAIL_PASS=your_app_password</pre> <blockquote>⚠️ <b>Never commit your <code>.env</code> file.</b> Make sure it is listed in <code>.gitignore</code>.</blockquote> <h3>4. Run the backend</h3> <pre>cd backend npm install npm start # or: node server.js</pre> <h3>5. Run the frontend</h3> <pre>cd frontend npm install npm run dev</pre> <p>The app will be available at <code>http://localhost:5173</code> (Vite default).</p> <h3>6. (Optional) Run as a desktop app with Electron</h3> <pre>cd frontend npm run electron # use the script defined in your package.json</pre> <h3>7. (Optional) Run with Docker</h3> <pre># Backend cd backend docker build -t billing-backend . # Frontend cd ../frontend docker build -t billing-frontend .</pre> <hr> <h2>📸 Screenshots</h2>
